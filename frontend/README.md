# Restaurant Leads — Frontend

SPA React + TypeScript (Vite) + Tailwind CSS. Interfaz del CRM de captación:
dashboard con KPIs y agenda, tabla de leads con filtros, ficha del restaurante
con registro de contactos y programación de seguimientos.

```bash
npm install
npm run dev        # http://localhost:5173 (requiere el backend en 8000)
npm run build      # build de producción (dist/)
```

Variables: copia `.env.example` a `.env` si el backend no está en
`http://127.0.0.1:8000/api/v1`. Usuarios de desarrollo (seed):
`admin@example.com` / `ventas@example.com` (pass `demo1234`).
